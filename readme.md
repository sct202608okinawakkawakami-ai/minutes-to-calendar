# 議事録タスク自動抽出＆Googleカレンダー連携アプリ (`minutes-to-calendar`)

## 1. アプリケーション概要
本アプリケーションは、会議の議事録テキスト（`input.txt`）をAI（Gemini API）によって解析・構造化し、抽出されたタスク（担当者・期日）をGoogleカレンダーへ自動的に個別登録するコンソール（CUI）バッチツールです。
システム開発における実運用を見据えた**「外部設定ファイルの分離（`.env`）」「堅牢な例外設計」「`.exe` 化による配布・実行容易性」**を考慮して設計されています。

---

## 2. 使用技術・開発環境
- **言語**: Python 3.15
- **AI連携**: Gemini API (`gemini-3.8-flash`)
- **カレンダー連携**: Google Calendar API (OAuth 2.0 認証)
- **環境設定管理**: python-dotenv (`.env`)
- **パッケージング**: PyInstaller (.exe化)
- **開発エディタ**: VS Code (Windows 環境)

## 4. 入力仕様書 (`input.txt` のフォーマット定義)
議事録を作成する際は、AIが確実にタスクと期日を抽出できるように以下の構造・形式で記述してください。

### 【記述ルール】
* **会議名・日時・参加者**: ヘッダー部分に明記する。
* **決定事項・メモ / タスク**: 「〜すること」「〜を担当」「〜までに〜」といった明確な表現を使用する。
* **期日の表現形式**: 
  * 日付のみ（終日予定）: `YYYY-MM-DD`（例: `2026-11-18`）
  * 時間指定あり: `YYYY-MM-DDTHH:MM` または `YYYY-MM-DDTHH:MM:SS`（例: `2026-11-19T15:00:00`）
  * 期日未設定の場合: 日付を指定しない（またはAIが `null` として判定）。

### 【記述例 (`input.txt` の内容)】
```text
【会議名】プロジェクト進捗確認MTG
【日時】2026年11月15日 10:00〜11:00
【参加者】山田、佐藤、田中

【決定事項・メモ】
・次回ミーティングは11月22日10:00から実施する。
・佐藤さんは11月18日までに基本設計書を修正して提出すること。
・山田さんは11月19日15:00からA社とのオンライン打ち合わせをGoogle Meetでセットする。
・開発環境の構築手順については、田中さんがwikiにまとめておく。
```

## 5. イレギュラー・エラー時の動作仕様（例外設計）
実運用時の安定性を確保するため、以下の例外処理をコード内に実装しています。

1. **入力ファイル不在 (`input.txt` がない場合)**
   * **動作**: クラッシュせず、エラーメッセージ `❌ エラー: 入力ファイル 'input.txt' が見つかりません` をコンソールに出力し、ユーザーのキー入力を待って安全に終了します。
2. **APIサーバー混雑・ネットワーク異常 (503エラー等)**
   * **動作**: 例外をキャッチし、`❌ Gemini API通信エラー` のログと詳細を出力して安全に停止します。
3. **AIの出力フォーマット不正 (JSONパースエラー)**
   * **動作**: `JSONDecodeError` をキャッチし、パース失敗の旨を通知して終了します。
4. **期日未設定タスク (`datetime: null`) の場合**
   * **動作**: 該当タスクをスキップし、`⚠️ 期日未設定のためスキップしました: [タスク名]` という警告ログを出力して、残りのタスクの登録処理を継続します。

## 6. 導入・実行手順

### ① 環境構築・事前準備
1. プロジェクトフォルダを配置（例: `C:\workspace\minutes-to-calendar`）。
2. 必要なライブラリのインストール:
   ```bash
   pip install google-genai google-auth-oauthlib google-api-python-client python-dotenv pyinstaller
   ```
3. `.env` ファイルの作成（プロジェクト直下）:
   ```env
   GEMINI_API_KEY=あなたのAPIキー
   INPUT_FILE=input.txt
   ```
4. `credentials.json` の配置（Google Cloud Consoleから取得）。

### ② スクリプトとして実行する場合
```bash
python main.py
```

### ③ `.exe` ファイルとして実行する場合（配布・実運用）
1. ビルドコマンドの実行（PyInstaller）:
   ```bash
   python -m PyInstaller --onefile main.py
   ```
2. 生成された `dist/main.exe` を、`.env` および `input.txt` と同じフォルダに配置し、`main.exe` をダブルクリックして実行します。
